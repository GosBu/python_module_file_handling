# Python Module: File Handling Demo

A small Python project showcasing core Python skills, including:

- **Modules & functions**  
- **File input/output** (read, write, append)  
- **Directory creation**  
- **Standard libraries** (`os`, `datetime`, `collections`)  
- **Modular, reusable code**

> Biological data (DNA sequences) is used as example input, but the focus is on Python, not biology.

---
## Features

1. **Module Functions**  
   - `opis_komorki()` – simple example function.  
   - `licz_nukleotydy(sequence)` – counts occurrences of characters in a string.  

2. **Directory Handling**  
   - Creates `dane_bio` folder if it doesn't exist.  
   - Stores output files in the created folder.  

3. **File Handling**  
   - Writes function results to a text file.  
   - Appends the current **date and time** to the file.  

4. **Python Skills Highlighted**  
   - Functions & modular code  
   - Standard libraries usage  
   - File & directory management  
   - Simple data processing  

---

## How to Run

1. Clone the repo:  

```bash
git clone https://github.com/GosBu/python_module_file_handling.git

```

2. Navigate to the project folder:

```cd module_file_handling```


3. Run the module:

```python biologia.py```


4. Check dane_bio/nukleotydy.txt for output.
